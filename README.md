# 多线推进 ThreadPusher · TauriTavern 扩展（独立版）

**解决的问题**：剧情铺了好几条线（未兑现的承诺、没解开的疑问、还没办的事、失踪的人……），但你不想每轮都主动去接——于是故事就停在原地，谁都不动。

这个扩展维护一份**线索台账**，自动找出"还挂在空中"的线索、判断它停滞了多久，并在**你没有主动推进**的时候，往提示词里注入一条指令：**本轮请把某条线往前推一步**。

**完全独立**：不需要世界书、不需要记忆链、不需要任何外部数据。装上就能用。

- 版本：1.0.0
- 适用：TauriTavern（也兼容 SillyTavern 前端的第三方扩展机制）
- 纯前端扩展：无后端依赖、无网络请求、不执行任何远程代码
- 默认零模型成本：线索靠规则抽取；可选用模型精修（默认关）

## 二、它怎么判断"该推了"

**线索从哪来**（三选一或全开，默认只开第一种）：

| 来源 | 说明 | 成本 |
| --- | --- | --- |
| **规则抽取**（默认） | 扫描最近 N 轮对话，抓"悬挂信号"的句子：承诺/约定（`下次｜改天｜等我｜要找｜去问｜调查｜打算｜尚未｜还没｜失踪｜来信｜听说…`）、疑问（问号或`为什么／怎么办／是否`）、消息类（信、口信、密报 + 未/没/等） | 零模型成本 |
| **模型精修**（可选，默认关） | 每隔 N 轮让便宜模型把"还挂着的线"整理成 JSON（含 `who`、`hint`、以及"已解决"的判定） | 每 N 轮一次安静请求 |
| **手动** | 面板「手动加一条」，或「编辑 JSON」批量改（可写 `hint` 给推进建议） | — |

**停滞怎么算**：按**轮**（用户消息数）。`停滞 = 当前轮 − 该线索最后一次被提到/被推的轮`；新建后从没碰过的一律排最前。阈值默认 **4 轮**。

**你算不算"被动"**（强度 1 下才会判）：消息为空／≤12 字／以`继续、随便、嗯、时间…`开头／**或者与所有线索都没有 2-gram 重合**——最后一条最准：你要是正在谈某条线，就不会被判定为被动。

## 三、注入长这样

单独槽位 `threadPusher`，注入深度默认 1（比记忆类条目更贴近最新消息）：

```
【多线推进·本轮任务】
玩家这一轮没有主动推动任何线索。请在本轮回复里让故事自己往前走：
1. 主线推进：师海客说他下次一定把那卷港图带来（已停滞 7 轮｜关联：师海客）　建议方式：他今天带着港图登门
背景信号（各一句带过，不要展开）：今年峰的雾比往年重，尚未查明原因
规矩：① 本轮只推进上述线索，不要顺手把别的线也解决；② 用场景、对话或消息自然带出，不要写成旁白交代；
      ③ 不替玩家做决定，把选择权留在玩家手里；④ 推进后留下新的小钩子。
```

## 四、三个"不抢戏"的设计

1. **你正在提的线不会被当主推对象**（除非强度 3）：用 2-gram 重合判断，命中就算"热"，本轮跳过它；
2. **冷却**：被推过的线索冷却 N 轮（默认 3）——主推的下轮还能被考虑，背景信号的进冷却；
3. **不会连推**：刚推过一轮，强度 1 至少隔 1 轮才会再推。

## 五、参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 启用 | 开 | 关掉就完全不注入 |
| 强度 | **1** | 0=关；1=只在用户被动时；2=每 N 轮必推；3=每轮都推 |
| 停滞轮数 | 4 | 低于此值不推（调大=更安静） |
| 每轮主线 / 背景信号 | 1 / 1 | 主线详细交代，背景一句带过；都可设 0 |
| 冷却（轮） | 3 | 被推过的线索多久内不再被选 |
| 强度2间隔 | 4 | 强度 2 时每隔几轮推一条 |
| 抽取窗口（轮）/ 注入深度 | 6 / 1 | 扫描多少轮对话；注入位置贴近最新消息 |
| 用模型精修 / 间隔 | 关 / 8 | 需要更懂语义的线索时再开 |

## 六、面板功能

- **线索列表**：每条显示来源、停滞轮数、已推次数，带「推一下」（定向推进，可改措辞）／「完成」／「删除」
- **立即扫描线索**：立刻按当前对话刷新台账（开了模型精修时会顺带调一次模型）
- **现在推一条**：立刻生成一条推进指令给你过目/修改
- **从记忆链导入（可选）**：若你同时装了「记忆链」扩展，可把它的章节卡"悬念"字段一次性导入台账——**纯可选，不装也能用**
- **清空本聊天的线索**：每个聊天各自一份台账，互不影响

## 七、存储

自动按优先级选后端：**TauriTavern 原生 store**（`data_root/_tauritavern/extension-store/thread-pusher/`）→ **IndexedDB** → 内存（面板黄字提示）。
设置是全局的；**线索台账按聊天隔离**（角色 + 存档），换档就是另一套线索。
